# AI-Assisted HND Final-Year Project Workflow

An advisor-style workflow for helping a Higher National Diploma (HND) student in Nigeria plan, research, build, document, and prepare to defend a final-year project. It uses AI to support the student's work while keeping research decisions, evidence, implementation, and final authorship reviewable by the student.

## Requirements

- An AI agent that can read and edit project files and, when research is needed, browse the web.
- The student's approved department or school project guidelines, where available.
- The student remains responsible for checking sources, collecting genuine data, testing the project, and following their institution's rules for AI use.

This folder contains instructions for an AI-assisted workflow. It is not a project generator that can guarantee institutional approval, original research, or a pass.

## How to use

1. Give the agent `SYSTEM_PROMPT.md` and ask it to follow the workflow.
2. Answer the intake questions with the proposed topic, department, institution, project type, current progress, and any available guidelines.
3. Work through the stages with the agent. Confirm important choices before it builds on them; verify facts, sources, data, and test results yourself.
4. Review and adapt every deliverable to your supervisor's feedback and your department's required format before submission.

## What it helps produce

- A focused, feasible project title, problem statement, aim, objectives, research questions, scope, and work plan.
- A source-backed proposal and chapter plan aligned to the student's actual department guidelines.
- A literature review with a traceable source matrix and identified research gap.
- A suitable, ethically sound methodology and real data collection instruments where needed.
- For software or engineering projects, requirements, design, implementation guidance, and a test plan grounded in the student's actual build.
- Draft chapter sections, references, appendices, presentation outline, and viva practice questions, all requiring student review.

## Workflow safeguards

- Never invent citations, quotations, survey responses, measurements, experiments, implementation details, or test results.
- Mark assumptions, unknowns, and unverified claims. Do not present generated text as evidence.
- Follow the student's school template and supervisor's instructions over generic chapter conventions.
- Keep participant consent, privacy, and data handling in view; do not collect sensitive information without a justified and approved plan.
- Support learning and transparent AI use. The student must understand, verify, and be able to defend the submitted work.
